# Анализ рынка вакансий для аналитиков

## Задача

Исследовать объявления с hh.ru за май и июнь 2024 года и определить основные тенденции рынка труда для аналитиков данных и системных аналитиков.

Датасет содержит сведения о работодателях, вакансиях, зарплатах, формате работы и требуемых навыках.

## Инструменты

- PostgreSQL;
- DBeaver;
- агрегатные функции, группировка, фильтрация и условные выражения.

## Что исследовано

1. Минимальные, максимальные и средние границы зарплатных вилок.
2. Регионы и работодатели с наибольшим количеством вакансий.
3. Распределение вакансий по типам занятости и графикам работы.
4. Требования к опыту аналитиков данных и системных аналитиков.
5. Зарплатные предложения и условия крупнейших работодателей.
6. Востребованные hard skills и soft skills для разных уровней опыта.

## Результаты

- 69% исследованных вакансий опубликованы в Москве.
- Более 90% вакансий для аналитиков требуют от 1 года до 6 лет опыта.
- Вакансии без требований к опыту встречаются заметно реже.
- Среди часто упоминаемых навыков — анализ данных, SQL, Python и pandas.
