# A/B-тест интерфейса интернет-магазина

Оценка статистического и бизнес-эффекта обновлённого интерфейса.

## Контекст

Интернет-магазин тестирует новый интерфейс и ожидает рост конверсии в покупку не менее чем на 3 процентных пункта.

## Задача

Определить, увеличивает ли интерфейс конверсию и достаточно ли наблюдаемого эффекта для глобального внедрения.

## Данные

14 525 записей об участниках экспериментов и 787 286 событий. После исключения пересечений в целевой тест вошли 9 963 пользователя.

## Метод

- исключены участники конкурирующего эксперимента;
- проверены баланс и независимость групп;
- удалены дубли, события ограничены первыми семью днями;
- рассчитана конверсия и выполнен односторонний z-тест пропорций.

## Результат

- конверсия выросла с 27,81% до 29,54%;
- абсолютный прирост — 1,73 п. п., относительный — 6,21%;
- различие статистически значимо: `p-value = 0,0283`;
- эффект не достигает бизнес-порога в 3 п. п.;
- на устройствах Mac обнаружен более сильный сегментный эффект.

## Рекомендации

Не внедрять интерфейс глобально только на основании текущего результата; отдельно проверить гипотезу для пользователей Mac.

## Ограничения

Сегментный результат требует отдельного подтверждения. Повторный анализ по нескольким сегментам повышает риск ложноположительных выводов.

## Инструменты

Python, pandas, NumPy, Matplotlib, Seaborn и statsmodels.
