# A/B-тест обучающего онбординга

Оценка влияния обучения инвестиционным рискам на депозитную активность пользователей.

![Историческая продуктовая воронка](./assets/historical-funnel.png)

## Контекст

Пользователи финтех-приложения могли покупать рискованные активы без полного понимания последствий. Команда добавила подробный онбординг, но опасалась снижения конверсии в первый депозит.

## Задача

Проверить влияние нового онбординга на первый и повторный депозиты, суммы пополнений и поведение покупателей активов разного риска.

## Данные

238 059 исторических событий и данные A/B-эксперимента с действиями новых пользователей в течение недели после регистрации.

## Метод

- исследованы историческая воронка и сегменты пользователей;
- проверены качество и баланс экспериментальных групп;
- рассчитаны конверсии и депозитные метрики;
- применены z-тест пропорций, t-тест Уэлча, поправка Бонферрони и бутстрэп.

## Результат

- конверсия во второй депозит выросла на 61%;
- конверсия в первый депозит статистически значимо не изменилась;
- средняя сумма депозитов среди платящих пользователей выросла на 4,4%;
- для покупателей высокорисковых активов конверсия во второй депозит выросла с 27,7% до 46,0%.

## Рекомендации

Рассмотреть адресное внедрение онбординга для пользователей, выбирающих рискованные активы, и продолжить наблюдение за долгосрочным поведением.

## Ограничения

Горизонт наблюдения ограничен одной неделей. Итоговая версия ноутбука сохраняет результаты, но повторный запуск требует учебных датасетов.

## Инструменты

Python, pandas, NumPy, Matplotlib, Seaborn, SciPy, statsmodels и bootstrap.
