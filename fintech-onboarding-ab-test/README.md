# A/B-тест обучающего онбординга

## Задача

Оценить, как подробное объяснение инвестиционных рисков влияет на первый и повторный депозиты пользователей финтех-приложения.

## Что сделано

- исследованы историческая воронка и поведение пользователей;
- проверены качество и баланс экспериментальных групп;
- рассчитаны конверсии и депозитные метрики;
- применены z-тест пропорций, t-тест Уэлча, поправка Бонферрони и бутстрэп;
- изучен эффект онбординга для покупателей активов разного уровня риска.

## Результаты

- Конверсия во второй депозит выросла на 61%.
- Конверсия в первый депозит статистически значимо не изменилась.
- Средняя сумма депозитов среди платящих пользователей выросла на 4,4%.
- Для покупателей высокорисковых активов конверсия во второй депозит выросла с 27,7% до 46,0%.
- Рекомендовано адресное внедрение онбординга и дальнейшая проверка долгосрочного эффекта.

## Инструменты

Python, pandas, NumPy, Matplotlib, Seaborn, SciPy, statsmodels, bootstrap.
