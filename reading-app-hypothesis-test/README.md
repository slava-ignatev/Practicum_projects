# Проверка гипотезы об активности читателей

Статистическое сравнение времени использования книжного приложения в Москве и Санкт-Петербурге.

## Контекст

Команда хочет понять, различается ли вовлечённость пользователей между двумя крупнейшими городами.

## Задача

Проверить гипотезу о том, что пользователи из Санкт-Петербурга проводят за чтением и прослушиванием больше времени, чем пользователи из Москвы.

## Данные

8 784 исходные записи с городом, идентификатором пользователя и суммарным временем активности.

## Метод

- проверены пропуски, полные дубликаты и повторяющиеся идентификаторы;
- сравнены размеры выборок и распределения активности;
- обработаны экстремальные значения;
- выполнен односторонний t-тест Уэлча.

## Результат

- в итоговую выборку вошли 8 454 пользователя;
- среднее время активности составило 8,29 часа в Москве и 8,96 часа в Санкт-Петербурге;
- `p-value = 0,09`, поэтому при уровне значимости 5% статистических оснований подтвердить гипотезу недостаточно.

## Рекомендации

Не принимать продуктовые решения только на основании наблюдаемой разницы средних; при необходимости повторить анализ на большей выборке и с дополнительной сегментацией.

## Ограничения

Удаление верхнего 1% наблюдений влияет на оцениваемую метрику. Данные не объясняют причины различий между городами.
