# Проверка гипотезы об активности читателей

## Задача

Проверить гипотезу о том, что пользователи книжного приложения из Санкт-Петербурга проводят за чтением и прослушиванием больше времени, чем пользователи из Москвы.

## Что сделано

- проверены пропуски, полные дубликаты и повторяющиеся идентификаторы;
- изучены размеры выборок и распределение времени активности;
- обработаны экстремальные значения;
- выполнен односторонний t-тест Уэлча для независимых выборок.

## Результаты

- В итоговую выборку вошли 8 454 пользователя: 6 038 из Москвы и 2 416 из Санкт-Петербурга.
- Среднее время активности составило 8,29 и 8,96 часа соответственно.
- `p-value = 0,09`: при уровне значимости 5% недостаточно оснований утверждать, что пользователи Санкт-Петербурга активнее.

## Инструменты

Python, pandas, NumPy, Matplotlib, Seaborn, SciPy.
