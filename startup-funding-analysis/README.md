# Анализ финансирования стартапов

## Задача

Исследовать рынок стартапов и инвестиционные возвраты до 2014 года, найти устойчивые сегменты и подготовить рекомендации для инвестиционной стратегии на 2015 год.

## Что сделано

- очищены данные о 54 тыс. компаний, обработаны пропуски и дубликаты;
- компании сегментированы по сроку финансирования и размеру рынка;
- выбросы рассчитаны отдельно внутри рыночных сегментов методом IQR;
- проанализированы динамика раундов, объёмы финансирования и возвратность инструментов;
- сформированы рекомендации по отраслям и типам финансирования.

## Результаты

- После предобработки в анализ вошли 40 907 компаний.
- Компании с финансированием дольше года привлекли 62,3% совокупного капитала.
- В 2014 году прошло 7 159 раундов, медианный размер раунда составил 575 тыс. долларов.
- Наиболее перспективными направлениями определены Real Estate / PropTech и SaaS.
- Основной рекомендуемый инструмент — венчурное финансирование; seed- и angel-инвестиции подходят для поиска ранних проектов.

## Инструменты

Python, pandas, Matplotlib, описательная статистика, IQR, сводные таблицы.
