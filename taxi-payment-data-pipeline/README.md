# Витрина поездок такси на PySpark и Airflow

Автоматизированный пайплайн от ежедневного Parquet-файла до аналитической витрины в ClickHouse.

![Архитектура пайплайна](./assets/pipeline.svg)

## Контекст

Финансовой и продуктовой командам нужна регулярно обновляемая сводка по способам оплаты поездок без ручного запуска расчётов.

## Задача

Дождаться входного файла в S3, обработать поездки распределённым Spark-заданием и записать агрегаты в ClickHouse.

## Данные

Ежедневные поездки в Parquet: способ оплаты, тариф, чаевые и общая стоимость поездки.

## Метод

- настроено чтение Parquet из S3 в PySpark;
- рассчитаны число поездок, средний тариф, средние чаевые и суммарная выручка;
- настроена запись витрины `taxi_payment_summary` через JDBC;
- подготовлен ежедневный Airflow DAG с `S3KeySensor` и запуском Yandex Data Proc;
- секреты и идентификаторы инфраструктуры вынесены из кода.

## Результат

В сохранённом результате обработано 2 540 712 поездок. Наличные лидируют по числу поездок, банковские карты — по суммарной выручке и среднему тарифу.

## Рекомендации

Для промышленного использования добавить контроль качества входных данных, идемпотентную запись по дате и мониторинг SLA пайплайна.

## Ограничения

Ноутбук использовался как шаблон передачи решения. Повторный запуск требует S3A-зависимостей, Airflow Connections и доступа к облачной инфраструктуре.

## Инструменты

PySpark, Apache Airflow, S3, Parquet, Yandex Data Proc, ClickHouse и JDBC.
