# Витрина поездок такси на PySpark и Airflow

## Задача

Автоматизировать ежедневную подготовку витрины по способам оплаты поездок: дождаться файла в S3, обработать Parquet в Spark и записать агрегаты в ClickHouse.

## Что сделано

- настроено чтение Parquet из S3 в PySpark;
- по каждому способу оплаты рассчитаны число поездок, средний тариф, средние чаевые и суммарная выручка;
- настроена запись витрины `taxi_payment_summary` через JDBC;
- подготовлен Airflow DAG с `S3KeySensor` и запуском задания в Yandex Data Proc;
- параметры подключения вынесены из кода в переменные окружения.

## Результаты

В сохранённом результате обработано 2 540 712 поездок. Наличные лидируют по количеству поездок, а банковские карты — по суммарной выручке и среднему тарифу.

## Инструменты

PySpark, Apache Airflow, S3, Parquet, Yandex Data Proc, ClickHouse, JDBC.

## Ограничения

Ноутбук использовался как шаблон передачи решения: локальный запуск требует настроенных S3A-зависимостей, Airflow Connections и доступа к инфраструктуре.
