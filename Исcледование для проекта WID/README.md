# Продуктовая аналитика WID

WID — учебный кейс цифрового гардероба для fashion-индустрии. Проект объединяет анализ продуктовых метрик, A/B-тест и операционный дашборд.

## Инструменты

- Python, pandas, NumPy, Matplotlib, Seaborn и statsmodels;
- PostgreSQL и DBeaver;
- DataLens;
- Jupyter Notebook.

## A/B-тест

**Задача:** оценить влияние регистрации через Яндекс ID на конверсию из визита в регистрацию.

Этапы анализа:

1. Сформулировать продуктовую и статистические гипотезы.
2. Выбрать ключевую метрику и минимальный размер выборки.
3. Проверить дубли, пересечение пользователей и размеры групп.
4. Рассчитать абсолютное и относительное изменение конверсии.
5. Проверить статистическую значимость с помощью z-теста пропорций.

**Результат:** конверсия составила 34,71% в контрольной группе и 41,88% в тестовой. Абсолютный прирост — 7,17 п. п., относительный — 20,64%. Односторонний z-тест показал статистически значимое различие: `p-value = 0,0191` при `alpha = 0,05`.

## Продуктовые метрики

В SQL рассчитаны:

- DAU, WAU и MAU;
- конверсии между этапами воронки;
- retention на 7-й и 30-й день;
- эффективность источников привлечения;
- различия между устройствами и площадками.

Основная потеря происходит между регистрацией и подпиской: до подписки не доходят 78% зарегистрированных пользователей. Retention составил 7% на 7-й день и 5,4% на 30-й день.
